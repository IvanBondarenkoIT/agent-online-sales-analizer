# Диалог #13

## Суть
კლიენტი (ნანა) იკითხავს აპარატის ფასს და ეჭვობს, მხოლოდ ნალექიანი (ფილტრის) ყავისთვისაა თუ არა. მენეჯერი მიმართავს სახელით, ცხრილს აძლევს ფასს (1899 ლარი ფასდაკლებით), აღწერს იტალიური სასმელების მომზადებას და ბოლოს კითხულობს, რომელ სასმელს სვამს ყველაზე ხშირად.

## Эмоция клиента
შიში, რომ არასწორ ტიპის აპარატს იყიდის — უნდა ფილტრის/ნალექიანი ყავა, და ეჭვობს, ეს მოდელი მხოლოდ ამისთვისაა თუ სხვა ფუნქციებსაც აკეთებს. ფასის მოთხოვნა ერთად მოდის ამ გაურკვევლობასთან — ჯერ უნდა გაირკვეს, შესაფერისია თუ არა.

- ფასი გაცხადდა «голым числом» — 1899 ლარი ფასდაკლების ნიშანით, მაგრამ ღირებულების/შედარების ჩარჩოს გარეშე
- ფასამდე არ გაირკვა პოტრეობა — რა ტიპის ყავას სვამს, სად გამოიყენებს, რა ეძებს
- პასუხი არაპირდაპირია: იტალიური სასმელების ჩამოთვლით ერთი ნაწილი გაირკვა, მაგრამ ნალექიანი ყავის შესაძლებლობა/შეზღუდვა არ იყო ნათლად ნათქვამი
- ბოლო კითხვა კარგია ჩართულობისთვის, მაგრამ არ არის გაყიდვის CTA — არ არის შემდეგი ნაბიჯი (შოურუმი, დემო, შეკვეთა, ზარი)
