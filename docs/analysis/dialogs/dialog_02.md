# Диалог #2

## Суть
Клиент спрашивает, сколько видов кофе готовит аппарат. Менеджер отвечает: 8 напитков в меню, можно создавать свои рецепты, модель «идеальна для дома», есть автоподача молотого кофе и молока, при покупке — обучение от тренера. Цена не названа, потребности клиента не выяснены.

## Эмоция клиента
Скрытый страх ограниченного выбора и сомнение «хватит ли возможностей аппарата под мои привычки». Клиент сравнивает варианты и хочет убедиться в универсальности, прежде чем идти дальше — менеджер это не распознал и не задал ни одного уточняющего вопроса.

## Ошибки менеджера

- Ответил на вопрос фактом (8 напитков), но не выяснил, зачем клиенту это важно — для дома, офиса, скольких человек, какие напитки пьют чаще
- Предположил «идеальна для дома» без подтверждения — риск промахнуться с позиционированием
- Отправил два длинных сообщения подряд без паузы — информационная перегрузка вместо диалога
- Не связал функционал с личной выгодой клиента («для вас это значит…»)
- CTA слабый: спросил про обучение от тренера, а не про следующий шаг к покупке (демо, модель, доставка, звонок)
- Цена не упомянута и не обёрнута в ценность — при сравнительном выборе клиент остаётся без якоря
