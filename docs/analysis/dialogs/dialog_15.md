# Диалог #15

## Суть
Клиент (Нана) интересуется ценой кофемашины для дома на семью из трёх человек. Менеджер несколько раз называет цену 1899 лари, задаёт уточняющие вопросы (дом/бизнес, автомат/механика, любимый напиток), но не выясняет бюджет заранее. Клиент дважды спрашивает цену, затем отказывается из‑за стоимости. Менеджер предлагает написать бюджет для подбора, без конкретных альтернатив.

## Эмоция клиента
Страх переплатить и финансовое ограничение — клиент хочет понять «сколько это стоит» до эмоционального вовлечения в продукт; скрытый триггер — «это дорого для нашей семьи, я не хочу стыдиться отказа»

## Ошибки менеджера

- Цена 1899 лари названа «голым числом» уже во 2-й реплике, до полного выявления потребностей и бюджета
- Клиент дважды спросил «ფასი?» — менеджер снова назвал ту же цену и ушёл в вопрос о напитках, не ответив на скрытый запрос о доступности
- Не задан вопрос о бюджете до презентации цены (критично для семьи из 3 человек)
- Вопрос об автоматической/механической машине (реплика 4) остался без ответа — менеджер потерял нить диалога
- На возражение «ვერ შევწვდები» нет эмпатии, нет альтернативных моделей, рассрочки или trade-in
- Финальный CTA пассивный («напишите бюджет») — клиент уже попрощался, диалог фактически закрыт без конкретного следующего шага
- Не использовано имя клиента (Нана) для персонализации до 6-й реплики, хотя контекст подразумевает знакомство
