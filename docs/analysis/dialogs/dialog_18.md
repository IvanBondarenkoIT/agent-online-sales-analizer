# Диалог #18

## Суть
კლიენტმა მოითხოვა ყავის აპარატის ფასი. მენეჯერმა (მაიკო) ჯერ შესთავაზა ფასდაკლებით 1899 ლარი და ჰკითხა, სახლისთვის ეძებს თუ არა. კლიენტმა დაადასტურა, რომ სახლისთვის სჭირდება. მენეჯერმა ამის ნაცვლად გადაერთო სრულ ასორტიმენტზე (ავტომატური 1300-დან, მექანიკური 470-დან) და ჰკითხა, რომელი ურჩევნია.

## Эмоция клиента
ფასის შეშინი და სწრაფი, გასაგები პასუხის მოთხოვნა — კლიენტი არ ეძებს კატალოგს, არამედ კონკრეტულ გადაწყვეტილებას. დადასტურების შემდეგ ჩნდება შეშფოთება: «1899-იანი შეთავაზება ჩემთვისაა თუ არა?», «არ ვირჩევ ცუდად?», «შემიძლია უფრო იაფი ვარიანტი?»

## Ошибки менеджера

- კლიენტის პირველივე მოთხოვნაზე (ფასი) პასუხი არ იყო სრული — 1899 ლარი უცნობი მოდელის გარეშე გაეცა
- კლიენტმა როცა დაადასტურა «სახლისთვის მინდა», მენეჯერმა არ გააგრძელა 1899-იანი შეთავაზება და არ დააკავშირა ის სახლის გამოყენებასთან
- ერთ დიალოგში სამი სხვადასხვა ფასის якорь (1899, 1300-დან, 470-დან) — ეს ბნედს ქმნის და კლიენტს აყოვნებს გადაწყვეტილებაზე
- არ გამოიკვლია მოცულობა, გამოცდილება, ბიუჯეტი ან რა ტიპის ყავა სურს — მხოლოდ ტიპის არჩევანი შესთავაზა
- კლიენტის ემოცია (ფასის მოკლე პასუხი) არ იყო აღიარებული და არ განმტკიცდა ღირებულება

## Фраза, убившая диалог
