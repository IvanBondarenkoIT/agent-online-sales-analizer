# Диалог #10

## Суть
კლიენტი იკითხავს ყავის აპარატის ფასს. მენეჯერი (ნათია) პასუხობს 1899 ლარით და ზოგად აღწერას. კლიენტი ორჯერ ითხოვს კონკრეტულ სასმელების სრულ სიას, შემდეგ კითხულობს — ონლაინ მაღაზია ხართ თუ არა. მენედჟერი ფილიალებს, ფასდაკლების პირობებს და ვიზიტს ახსნის, მაგრამ ონლაინ შეძენის მარტივ გზას არ იძლევა.

## Эмоция клиента
შიში, რომ მას misleading ინფორმაცია აძლევენ და პროდუქტი არ არის ის, რაც ეჩვენება; სჭირდება გამჭვირვალობა, სრული სია და დარწმუნება, რომ ონლაინ/ფიზიკურად უსაფრთხოდ იყიდის

## Ошибки менеджера

- ფასი (1899 ლარი) პირველ პასუხში „голым числом“ გაეცა — ჯერ პოტребность не выявлена
- კლიენტის კონკრეტულ კითხვაზე („რა სახის ყავას ამზადებს?“) პირველად სრულიად გვერდი აუარა და მარკეტინგული ფრაზები გაიმეორა
- მეორე პასუხშიც სასმელების სია არასრულია — „და ასე შემდეგ“-ით დატოვა
- „ონლაინ მაღაზია ხართ?“ — პირდაპირ „დიახ“ არ უპასუხა; პასუხი დაბნეული და პირობებით
- ფასდაკლების პირობებმა (მხოლოდ ონლაინ, ადგილზე წინასწარ მოწერა) დამატებითი ხელსაყრელი შექმნა
- CTA ფიზიკურ ვიზიტზეა, მაშინ როცა კლიენტი ოнлайн-каналზეა

## Фраза, убившая диалог
> კიბატონო, სახლისთვის იდიალური ვარიანტია, როგორც მოგწერეთ ძალიან გემრიელ ყავას ამზადებს და ყოველდღე მიირთმევთ არომატულ ყავას
