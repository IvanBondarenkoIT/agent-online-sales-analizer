# Диалог #16

## Суть
კლიენტმა ჰკითხა საოცარი (ავტომატური) ყავის აპარატის ფასი. მენეჯერმა უპასუხა 1899 ლარი (ფასდაკლებით) და აღწერა 8 სასმელი. კლიენტმა გამოხატა ინტერესი და ჰკითხა, არის თუ არა მსგავსი აპარატი 1500 ლარის ფარგლებში. მენეჯერმა ბიუჯეტზე პირდაპირ არ უპასუხა, არამედ გადაამისამართა მექანიკურ აპარატებზე 470 ლარიდან, რომლებსაც ჩაშენებული საფქვავი არ აქვთ.

## Эмоция клиента
ბიუჯეტის შიში და უსაფრთხოების მოძებნა — კლიენტი 1899-ს ძვ дорого-ს უგრძნობს და ეძებს იგივე კლასის, მაგრამ ხელმისაწვდომ ალternativas-ს. მისი ფარული ემოცია: «არ გადავიხდი ზედმეტს» და «არ მინდა უფრო იაფ, მაგრამ უარესი ვარიანტი».

## Ошибки менеджера

- ფასი (1899) გა sounded 'голым числом' — პირველ რიგში არ გამოიკვლია, რა სჭირდება კლიენტს, პირდაპირ ციფრი თქვა
- კლიენტის კონკრეტულ კითხვაზე (1500 ლარის ფარგლებში მსგავსი აპარატი) არ უპასუხა პირდაპირ
- ბიუჯეტის ჩარჩოს იგნორირება და სრულიად სხვა კატეგორიაზე გადაყვანა (მექანიკური 470-დან) — bait-and-switch ეფექტი
- «მსგავსი» აპარატის მოთხოვნა (ავტომატური, ჩაშენებული საფქვავით) არ დაკმაყოფილდა
- კითხვა «სახლისთვის ეძებთ?» ორჯერ გამეორდა, პასუხი არ მიიღო — რობოტური და არაემპათიური
- CTA სუსტია — არ შესთავაზა კონკრეტული მოდელი, ფასი, განვადება ან შემდეგი ნაბიჯი
- კლიენტის «იცი რა» (პირადი/ემოციური ტონი) არ აღიქმა — არ გამოიხმარია ემპათია

## Фраза, убившая диалог
> ჩვენთან მექანიკური ყავის აპარატის ფასები იწყება 470 ლარიდან, უბრალოდ ამ მოდელებს არ აქვს ჩაშენებული საფქვავი
