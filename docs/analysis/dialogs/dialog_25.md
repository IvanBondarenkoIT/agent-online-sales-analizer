# Диалог #25

## Суть
Клиент спросил только о цене кофемашины. Менеджер сразу назвал цену со скидкой — 1899 лари — описал продукт (8 видов напитков) и в конце задал уточняющий вопрос, ищет ли клиент аппарат для дома.

## Эмоция клиента
Скрытый страх переплатить и сравнительный шопинг: клиент начал с цены, значит сравнивает варианты и хочет быстро понять, «вписывается ли» предложение в бюджет, прежде чем вникать в детали.

## Ошибки менеджера

- Менеджер сразу озвучил «голую» цену (1899 лари) без предварительного выявления потребностей
- Не задал вовлекающий вопрос до цены — ответил на «ფასი?» только цифрой и описанием продукта
- Не выяснил, для чего нужна машина, какой бюджет, опыт использования — сразу предположил «для дома»
- Цена названа без ценностного контекста (экономия, сравнение с кофейней, что входит в комплект)
- CTA слабый: общий вопрос вместо конкретного следующего шага (резерв, демо, отправка фото/видео, звонок)
