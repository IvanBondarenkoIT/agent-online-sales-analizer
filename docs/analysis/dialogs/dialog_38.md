# Диалог #38

## Суть
Клиент спросил только цену кофемашины. Менеджер сразу назвал цену со скидкой (1899 лари), перечислил характеристики и в конце задал один уточняющий вопрос — для дома ли нужен аппарат.

## Эмоция клиента
Ценовая тревога и желание быстро сравнить варианты без лишнего разговора. Клиент, скорее всего, уже смотрит несколько предложений и боится переплатить или попасть в навязчивую продажу — поэтому спросил максимально коротко.

## Ошибки менеджера

- Менеджер не выявил потребности до цены — сразу назвал «голое» число 1899 лари
- Не поздоровался по имени и не установил контакт перед продажей
- Не уточнил контекст: дом/офис, бюджет, опыт, сколько чашек в день
- Длинное описание функций без привязки к запросу клиента — перегруз информацией
- Слабое завершение: вопрос «для дома?» вместо конкретного призыва к действию (заказ, визит, выбор модели, звонок)
- Не снял скрытый страх «дорого / не то куплю» — не обрамил цену ценностью под задачу клиента
