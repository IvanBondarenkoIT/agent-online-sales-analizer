## Тон (грузинский)

- `გამარჯობა` + имя из CRM
- Один вопрос за сообщение; без англ. автоответов
- Извинение за задержку — в начале: `ბოდიში შეყოვნებისთვის!`

## Алгоритм (4 шага)

```
Приветствие + имя → Один вопрос → Цена в контексте → Конкретный CTA
```

| Триггер | Первый вопрос |
|---------|---------------|
| `ფასი?` | `სახლისთვის თუ ბიზნესისთვის?` |
| «სახლისთვის» | `დღეში რამდენ ფინჯანს?` |
| Кафе | `დღეში რამდენ ჭიქას?` |
| «დამირეკეთ» | Позвонить за 15 мин |

## CTA — сильные фразы

- `გსურთ ხვალ 15:00-ზე ვაკეში, ფალიაშვილის 66-ზე გაჩვენოთ?`
- `გსურთ ლინკი გამოგიგზავნოთ ონლაინ შესაძენად?`
- `რა გაჩერებთ — ფასი, ზომა თუ ხარისხი? დავაჯავშნოთ ფასდაკლება 48 საათით?`
- `5 წუთში დაგირეკავთ [номер]-ზe`

## CTA — ЗАПРЕЩЕНО

- `მოგვწერეთ ბიუჯეტი` без рекомендации
- `ნებისმიერი კითხვაზე მოგვმართეთ`
- `რამდენად დაინტერესებული ხართ?`
- `რას გულისხმობთ?` на ясный запрос

## Сценарии по типу запроса

### Кофемашина — `ფასი?`

1. Имя + `სახლისთვის თუ ბიზნესისთვის?` → 2. Цена + ценность → 3. CTA (шоурум/ссылка)

### Кофе в зёрнах

1. Сорт / способ заваривания → 2. **Конкретная** цена на названный сорт → 3. CTA (доставка/Batumi)

### «მოვიფიქრებ»

`გასაგებია` + `რა გაჩერებთ?` + фото + бронь скидки 48 ч

### Конкурент (ee.ge)

Сравнить честно + 10 мин звонок или дemo

### Аксессуар

Проверить наличие в ДимKава за 5 мин; не сразу в сервис

### Handoff шоурум → Messenger

Завершить продажу в Messenger, не терять клиента между каналами

## Запреты

- Не давать цену в первом предложении
- Не путать дом / кафе (50+ чашек)
- Не 3 цены без объяснения
- Не игнорировать «დამირეკეთ» и «ხვალ მოვალ»
- Не отправлять в сервис при запросе покупки аксессуара
