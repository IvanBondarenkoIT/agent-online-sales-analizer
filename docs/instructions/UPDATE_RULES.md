# Правила обновления инструкций (для тренера)

**Для кого:** руководитель / тренер  
**Оператор этот файл не читает** — ему Playbook GE + Training GE.

Активный корпус анализа: **CRM с 14.07.2026** (`docs/analysis/CRM_REPORT_*.md`).  
DOCX «41 диалог» — архив; **не** источник новых правил.

---

## 7 принципов (Messenger / specialty retail)

1. **Скорость** — в рабочее время (10–18, пн–пт, Tbilisi) ответ ≤ **2 мин**.
2. **Один вопрос** — который меняет рекомендацию (дом/бизнес, нагрузка, модель).
3. **Цена после контекста** — не в первом предложении; цифра + польза.
4. **Один конкретный CTA** — время / звонок / ссылка / бронь.
5. **Один оффер = одна цена** — чат = сайт = шоурум.
6. **История CRM** — возвратный лид не с нуля.
7. **Нет в наличии / сервис / жалоба** — альтернатива + шаг + эмпатия; не обрыв.

Не добавляем чатбот-архитектуру, новые KPI сверх CRM, длинные фреймворки.

---

## Цикл после новых дней анализа

1. Открыть новые `CRM_REPORT_YYYY-MM-DD.md` (или period).
2. Взять: top_errors, слабые % чеклиста, 3–5 худших диалогов.
3. **Патч инструкций** только если паттерн:
   - новый, **или**
   - старое правило системно ломается (≥2 дня или ≥3 диалога).
4. Один патч = **1 правило + 1 скрипт GE + 1 кейс** «было→надо» (или правка существующего).
5. Обновить **RU и GE в одном коммите** (полное зеркало).
6. В шапке Playbook/Training: `Срез CRM: …`.
7. В §12 Training держать **5–8** актуальных кейсов; старые — архив-строка или удалить.
8. Чеклист оператора: максимум ~10 пунктов; новый системный провал → **один** новый пункт.

Если паттерн редкий — только планёрка / один кейс, без правки правил.
