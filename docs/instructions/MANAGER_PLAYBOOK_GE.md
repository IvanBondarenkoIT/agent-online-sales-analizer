1. **ფასი-დუმილი** — `ფასი?` → `აქციაშია — 1899₾` პირველ წინადადებაში.
2. **სუსტი CTA** — `მოგვწერეთ ბიუჯეტი` / ნაბიჯის გარეშე.

## 2. პასუხის ალგორითმი (4 ნაბიჯი)

```
კლიენტი → 1. გამარჯობა + სახელი → 2. ერთი კითხვა → 3. ფასი კონტექსტში → 4. კონკრეტული CTA
```

| ნაბიჯი | რა გააკეთო | მაგალითი |
|--------|-----------|----------|
| 1 | სახელი | `გამარჯობა [სახელი]!` |
| 2 | ერთი კითხვა | `სახლისთვის თუ ბიზნესისთვის?` |
| 2′ | დატვირთვა | `დღეში რამდენ ფინჯანს/ჭიქას?` |
| 3 | ფასი + სარგებელი | `ფასდაკლებით X ლარია — ჩაშენებული საფქვავით...` |
| 4 | CTA | `გსურთ ხვალ 15:00-ზე ვაკეში გაჩვენოთ?` |

**აკრძალვა:** პირველ წინადადებაში არა `ლარი` და ფასის ციფრი.

## 6. დამატებითი წესები (CRM 21–27)

### 6.1 დაბრუნებული ლიდი
გახსენი ისტორია. არ გააგზავნო ისევ 1899 და «სახლისთვის?».  
`გამარჯობა! მაისში [მოდელი] გირჩიეთ — კვლავ აქტუალურია? ხვალ 15:00 ვაკეში გაჩვენოთ?`

### 6.2 მარაგში არაა
არ შეწყვიტო. ორი ვარიანტი: ანალოგი / ნაკრები / შეტყობინება + ვიზიტი ან შეკვეთა.

### 6.3 დაპირება = შოურუმი
საჩუქარი, სწავლება, ფერი — შეამოწმე ვიზიტამდე. საჩივარზე — ემპათია + ტრენერის სლოტი, არა `სად შეიძინეთ?`.

### 6.4 «უფრო იაფი გაქვთ?»
არა კედელი «სხვები 3500-დან». განვადება / დემო / ბიუჯეტის მოდელი + CTA.

### 6.5 ერთი ფასი
ერთი მოდელი = ერთი საბოლოო ციფრი გადახდამდე. ფასდაკლება ჩატში სამჯერ არ შეცვალო.

### 6.6 ორშაბათი
დილით შაბათ-კვირის თრედების triage; 70+ საათი პასუხის გარეშე — აკრძალულია.

## 8. ჩეკლისტი გაგზავნამდე

ყოველ გამავალ შეტყობინებამდე (~5 წამი):

- [ ] CRM-ში დიალოგის ისტორია გავხსენი?
- [ ] კლიენტის **სახელი** არის?
- [ ] პირველ წინადადებაში **არა** ფასი / `ლარი`?
- [ ] **ერთი** დამაზუსტებელი კითხვა (თუ ჯერ გაურკვეველია)?
- [ ] ფასი (თუ დროა) — კონტექსტში, **ერთი** ციფრი?
- [ ] ბოლოში — **კონკრეტული** ნაბიჯი (დრო / ზარი / ლინკი / დაჯავშნა)?
- [ ] მარაგი/სერვისი/საჩივარი — არის ალტერნატივა + ნაბიჯი?
- [ ] დაპირება (საჩუქარი, ფასდაკლება, სწავლება) ემთხვევა შოურუმს?
- [ ] პასუხი ≤ **2 წთ** სამუშაო დროს (10–18)?
