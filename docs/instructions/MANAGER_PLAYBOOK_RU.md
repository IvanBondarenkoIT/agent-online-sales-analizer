## 2. Алгоритм каждого ответа (4 шага)

```
Клиент → 1. Имя + приветствие → 2. Один вопрос → 3. Цена в контексте → 4. Конкретный CTA
```

| Шаг | Что делать | Пример клиенту |
|-----|------------|----------------|
| 1 | Имя | `გამარჯობა [სახელი]!` (Здравствуйте, [имя]!) |
| 2 | Один вопрос | `სახლისთვის თუ ბიზნესისთვის?` (Для дома или бизнеса?) |
| 2′ | Нагрузка | `დღეში რამდენ ფინჯანს/ჭიქას?` (Сколько чашек в день?) |
| 3 | Цена + польза | `ფასდაკლებით X ლარია — ჩაშენებული საფქვავით...` |
| 4 | CTA | `გსურთ ხვალ 15:00-ზე ვაკეში გაჩვენოთ?` (Завтра в 15:00 в Ваке показать?) |

**Запрет:** в первом предложении нет `ლარი` и цифры цены.

## 3. Ошибка №1: Цена-Молчание

Клиент: `ფასი?` / `რა ღირს` → мы начинаем с цены → клиент уходит с цифрой.

**Плохо:** `ეს მოდელი ახლა აქციაშია — 1899₾`  
**Надо:**

```
გამარჯობა [სახელი]! ☕️ სანამ ფასს გეტყვით —
სახლისთვის გჭირდებათ თუ ბიზნესისთვის?
```
(Пока не назову цену — для дома или для бизнеса?)

После ответа: одна цена + 1 польза + CTA.

---

## 4. Ошибка №2: Слабый CTA

| Нельзя | Надо |
|--------|------|
| `მოგვწერეთ ბიუჯეტი` (напишите бюджет) | `გსურთ ხვალ 15:00-ზე ვაკეში, ფალიაშვილის 66-ზე გაჩვენოთ?` |
| `ნებისმიერ კითხვაზე მოგვმართეთ` | `გსურთ ლინკი გამოგიგზავნოთ ონლაინ შესაძენად?` |
| `განიხილავთ ამ ვარიანტს?` | `რა გაჩერებთ — ფასი, ზომა თუ ხარისხი? დავაჯავშნოთ ფასდაკლება 48 საათით?` |

## 5. Ошибка №3: Дом vs бизнес / контекст

| Сигнал | Вопрос | Дальше |
|--------|--------|--------|
| `ფასი?` | `სახლისთვის თუ ბიზნესისთვის?` | Модель не называть до ответа |
| `სახლისთვის` | `დღეში რამდენ ფინჯანს?` `რძიანი?` | 1–2 модели с ценой |
| Кафе / B2B | `დღეში რამდენ ჭიქას?` | Модель под нагрузку + демо |

## 6. Дополнительные правила (CRM 21–27)

### 6.1 Возвратный лид
Открыть историю. Не слать снова шаблон 1899 и «для дома?».  
`გამარჯობა! მაისში [მოდელი] გირჩიეთ — კვლავ აქტუალურია? ხვალ 15:00 ვაკეში გაჩვენოთ?`

### 6.2 Нет в наличии
Не обрывать. Две опции: аналог / набор / уведомление + визит или заказ.

### 6.3 Обещание = шоурум
Подарок, обучение, цвет — сверить до визита. На жалобу — эмпатия + слот тренера, не `სად შეიძინეთ?`.

### 6.4 «Есть дешевле?»
Не стена «другие от 3500». Рассрочка / TCO / демо / модель в бюджете + CTA.

### 6.5 Одна цена
Одна модель = одна финальная цифра до оплаты. Скидку не менять в чате трижды.

### 6.6 Понедельник
Утром triage суббота–воскресенье; не оставлять 70+ часов без ответа.

## 7. Сценарии — шпаргалка

| Триггер | Первый ход | Когда цена | CTA |
|---------|------------|------------|-----|
| `ფასი?` | дом/бизнес | после ответа | визит / ссылка |
| `სახლისთვის` | чашки / молоко | 2-е сообщение | фото + звонок |
| Кафе | чашки/день | с нагрузкой | демо шоурум |
| `მოვიფიქრებ` | что останавливает | не повторять цену | бронь 48 ч |
| Нет в наличии | 2 альтернативы | по выбранной | заказ / визит |
| Жалоба после покупки | эмпатия | — | слот / замена |

### Шаблон «ფასი?»

**Шаг 1:** `გამარჯობა [სახელი]! ☕️ სანამ ფასს გეტყვით — სახლისთვის გჭირდებათ თუ ბიზნესისთვის?`  
**Шаг 2:** `ამ მოდელის ფასდაკლებით [X] ლარია — [польза]. გსურთ [конкретный шаг]?`

## 8. Чеклист оператора (перед каждым ответом)

Тот же список, что в GE — требовать с оператора:

- [ ] Открыл историю диалога в CRM?
- [ ] Есть **имя** клиента?
- [ ] В **первом** предложении нет цены / `ლარი`?
- [ ] Задан **один** уточняющий вопрос (если ещё не ясно)?
- [ ] Цена (если пора) — в контексте, **одна** цифра?
- [ ] В конце — **конкретный** шаг (время / звонок / ссылка / бронь)?
- [ ] Нет в наличии / сервис / жалоба — есть альтернатива + шаг?
- [ ] Обещание (подарок, скидка, обучение) совпадает с шоурумом?
- [ ] Ответ ≤ **2 мин** в рабочее время (10–18)?
