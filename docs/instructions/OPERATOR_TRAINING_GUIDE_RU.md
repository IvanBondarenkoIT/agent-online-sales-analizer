---

## 1. Главное правило: 4 шага

1. Приветствие + имя  
2. **Один** уточняющий вопрос  
3. Цена **в контексте** задачи  
4. **Конкретный** CTA (время / звонок / ссылка / бронь)

Без цены в первом предложении. Без «напишите бюджет».

---

## 2. Выявление потребности

Спросить то, что меняет модель: дом/бизнес, чашки в день, молочные напитки, срочность.

| GE | RU |
|----|-----|
| `სახლისთვის თუ ბიზნესისთვის?` | Для дома или для бизнеса? |
| `დღეში რამდენ ფინჯანს/ჭიქას?` | Сколько чашек в день? |
| `რძიანი კაპუჩინო გინდათ ერთი ღილაკით?` | Капучино одной кнопкой? |

Не допрос из 5 вопросов подряд.

---

## 3. Ответ на «ფასი?» / «რა ღირს?»

**Плохо:** `ეს მოდელი ახლა აქციაშია — 1899₾`  
**Хорошо:**

```
გამარჯობა [სახელი]! ☕️ სანამ ფასს გეტყვით —
სახლისთვის გჭირდებათ თუ ბიზნესისთვის?
```

После ответа: одна цена + 1 польза + CTA.

---

## 4. CTA

| Слабо | Сильно |
|-------|--------|
| `მოგვწერეთ ბიუჯეტი` | `ხვალ 15:00 ვაკე, ფალიაშვილის 66` |
| `ნებისმიერ კითხვაზე...` | `ლინკი ონლაინ` / `5 წუთიანი ზარი` |
| `განიხილავთ?` | `დავაჯავშნოთ ფასდაკლება 48 საათით?` |

На `მოვიფიქრებ`: что останавливает + бронь / фото / звонок.

---

## 5. Ценности ДимКава (когда уместно)

Обучение тренером, гарантия, доставка/монтаж, шоурум — **после** потребности, не вместо вопроса. Не списком до выяснения задачи.

---

## 6. Возражения

- «Дорого / есть дешевле?» → не стена «другие от 3500». Рассрочка, демо, модель в бюджете, TCO чашки.  
- «Подумаю» → уточнить блокер + конкретный шаг.  
- Банк/рассрочка зависла → альтернативы оплаты + бронь аппарата, не «это только банк».

---

## 7. Закрытие

Зафиксировать: день/час визита, звонок, ссылку, бронь. `next_step_fixed` в CRM сейчас ~0–10% — это главный провал.

---

## 8. Скорость ответа

| Блок | SLA |
|------|-----|
| Рабочее 10–18 пн–пт (Tbilisi) | ≤ **2 мин** (рабочие секунды) |
| Вне смены | ≤ **15 мин** мягко; не сутки+ |
| После «კი» / готов купить | жёсткий приоритет |

Понедельник утром — разбор выходных тредов.

---

## 9. Приветствие, имя, тон

`გამარჯობა [სახელი]!` · `კიბატონო` · грузинский · без автоответа на EN.

---

## 10. Сценарии

### 10.1 Цена без контекста
→ §3.

### 10.2 B2B / кафе
Нагрузка чашками → модель → демо/окупаемость → время визита.

### 10.3 Запчасть / сервис
Покупка в ДимКава ≠ «сами в сервис». Сначала наличие у нас; если сервис — дать телефон **и** проверить, что клиент дозвонился / предложить сопроводить.

### 10.4 Возвратный лид
История CRM: `მაისში [მოდელი] გირჩიეთ — კვლავ აქტუალურია?`

### 10.5 Нет в наличии
Две альтернативы + уведомление/заказ/визит.

### 10.6 Жалоба после покупки
Эмпатия → сверка обещания → слот тренера / замена. Не `სად შეიძინეთ?`.

### 10.7 «Есть дешевле?»
Одна модель в бюджете + рассрочка + демо, не upsell-стена.

## 11. Запретные фразы

| Нельзя | Почему |
|--------|--------|
| Цена в первом предложении | Цена-Молчание |
| `მოგვწერეთ ბიუჯეტი` | Пассив |
| Три разные цены подряд | Хаос, потеря доверия |
| Скидка −15% → «нельзя» → −5% | Целостность оффера |
| Игнор истории CRM | Повторная квалификация с нуля |
| Обрыв «არ გვაქვს» без шага | Потеря лида |

| Madonna / Гога | 27.07 | Одна модель = одна цена |

### 12.1 Lali — возвратный лид
**Было:** снова 1899 + «для дома?» после выбора ~1200.  
**Надо:** `გამარჯობა! მაისში [მოდელი] 1200₾ გირჩიეთ — კვლავ აქტუალურია? ხვალ 15:00 ვაკეში გაჩვენოთ?`

### 12.2 Mariana — нет в наличии
**Было:** только «таблеток нет».  
**Надо:** набор / аналог / «შეგატყობინებთ მარაგზე» + визит или заказ.

### 12.3 Marita — хаос скидки
**Было:** −15% вручную → «на скидку нельзя» → путаница.  
**Надо:** одна письменная финальная цена до оплаты.

### 12.4 Bacho — шоурум ≠ чат
**Было:** обещали подарок/обучение; в магазине отказ + `სად შეიძინეთ?`.  
**Надо:** сверка до визита; на жалобу — извинение + слот тренера сегодня.

### 12.5 Anamaria — «дешевле?»
**Было:** цена первой; на drive-through — «для дома?»; на «дешевле» — нет, другие от 3500; «подумаю» без CTA.  
**Надо:** контекст B2B → одна модель → рассрочка/демо → бронь 48 ч.

### 12.6 Madonna / Гога — flip цен
**Было:** 2859 ↔ 1899; месяцы без одной таблицы.  
**Надо:** модель — цена (одна строка) + дата визита.

### 12.7 Khatia — банк
**Было:** `ვერ დაგეხმარებით… საბანკო პროცესია`.  
**Надо:** альтернатива оплаты + бронь аппарата + звонок.
