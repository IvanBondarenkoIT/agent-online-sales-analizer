## 1. Главное правило: 4 шага

### Теория

Клиент в Messenger **не пришёл за цифрой**. Он пришёл понять: «Мне это подойдёт? Не переплачу? Можно ли доверять?»

Если вы сразу даёте цену — клиент получает информацию и **уходит думать один**, часто к конкуренту. Ваша задача — стать **консультантом**, который ведёт к решению.

**Формула каждого ответа:**

```
Приветствие + имя → Один уточняющий вопрос → Цена в контексте → Конкретный CTA
```

| Шаг | Зачем | Ошибка команды (среднее CRM 20.07) |
|-----|-------|-------------------------------------|
| 1. Контакт | Доверие, «со мной говорят лично» | Имя не используется в 54% диалогов |
| 2. Потребность | Подобрать модель, не «1899 всем» | needs_id = **1.29 / 5** |
| 3. Цена в контексте | Цифра + «зачем это вам» | price_in_context = **16.7%** |
| 4. CTA | Зафиксировать следующий шаг | concrete_cta = **4.2%** |

**Жёсткий запрет:** в первом предложении ответа не должно быть слова `ლარი`, `₾` или любой цены.

## 2. Выявление потребности

### Теория

«Выявление потребности» — это не анкета из 10 вопросов. Это **один правильный вопрос**, который меняет рекомендацию.

Цель: понять **сегмент** (дом / бизнес), **нагрузку** (чашек в день), **приоритет** (молочные / чёрный кофе / простота), **срок** (сегодня / через месяц), **бюджет** (если клиент сам не назвал).

### Иерархия вопросов

Задавайте **по одному** за сообщение. Не списком.

| Если клиент написал… | Первый вопрос | Второй вопрос (после ответа) |
|----------------------|---------------|------------------------------|
| `ფასი?` / `რა ღირს?` | `სახლისთვის თუ ბიზნესისთვის?` | `დღეში რამდენ ფინჯანს/ჭიქას?` |
| `სახლისთვის` | `დღეში რამდენ ფინჯანს სვამთ?` | `რძიანი კაპუჩინო/ლატე ერთი ღილაკით?` |
| «Открываю кафе» | `დღეში დაახლოებით რამდენ ჭიქას?` | `როდის იხსნება?` |
| «Сравниваю с Delonghi / ee.ge» | `რა ბიუჯეტში ეძებთ?` | `რომელი ფუნქცია ყველაზე მნიშვნელოვანია?` |
| «Дешевле есть?» | `რა სასმელებს სვამთ ყველაზე ხშირად?` | `ავტომატური (ჩაშენებული საფქვავი) თუ მექანიკური?` |
| Фото конкретной модели | `სახლისთვის თუ ოფისისთვის?` | `რომელი სასმელი გიყვართ?` |

### Сигналы в сообщении клиента — не переспрашивайте вслепую

| Сигнал в тексте | Что уже понятно | Спросите вместо «дом или бизнес» |
|-----------------|-----------------|----------------------------------|
| «კაფე», «რესტორანი», «drive-through» | Бизнес | `დღეში რამდენ ჭიქას?` |
| «სახლისთვის», «ოფისისთვის» | Сегмент известен | `დღეში რამდენ ფინჯანს?` |
| «1300 ლარი», «400 ლარი» | Бюджет | `რა სასმელებს prefer-ებთ?` |
| «ხვალ მოვალ», «დღეს ვიყიდი» | Горячий лид | Сразу CTA на визит/бронь |
| «დამირეკეთ» + номер | Звонок | Позвонить в течение 15 мин |

### Пример: правильное выявление (дом)

**Клиент:** `გამარჯობა, ფასი?`

**Плохо:** сразу `1899 ლარი`.

**Правильно:**

```
გამარჯობა თაკო! ☕️ სანამ ზუსტ ფასს გეტყვით —
სახლისთვის გჭირდებათ თუ ოფისისთვის?
```

После ответа «სახლისთვის»:

```
სuper! დღეში დაახლოებით რამდენ ფინჯანს სვამთ?
და რძიანი კაპუჩინო/ლატე გინდათ ერთი ღილაკით, თუ კლასიკური ესპრესო საკმარისია?
```

### Пример: правильное выявление (кафе)

**Клиент:** «Открываю кафе в Рача, нужна мощная машина»

**Плохо:** предложить домашнюю модель за 1899.

**Правильно:**

```
გამარჯობა! კაფე რაჭაში — საუკეთესო სცენარია ☕️
დღეში დაახლოებით რამდენ ჭიქას გეგმავთ — 30-40, 50-80 თუ მეტს?
და როდის იხსნება — ამ თვეში თუ სეზონში?
```

## 3. Ответ на «ფასი?» / «რა ღირს?»

### Теория: паттерн «Цена-Молчание»

Это **главная ошибка** команды. Клиент: `ფასი?` → оператор: `1899 ლარი` → клиент: `მადლობა` → **тишина**.

**Почему так происходит:** оператор думает, что вопрос = запрос прайса. На самом деле вопрос = «заинтересуй меня».

**Правило подачи цены:**

1. Цена — **после** одного уточняющего вопроса (минимум).
2. Цена — **с привязкой к задаче клиента**: «для вашего кафе 50 чашек…», «для семьи 3–4 чашки…».
3. Цена — **с одной ценностью**: не список из 5 услуг абзацем, а 1–2 пункта, релевантных клиенту.
4. В одном сообщении — **одна основная цена**. Не 1899 + 1300 + 470 в одном тексте.

### Шаблон (2 сообщения)

**Сообщение 1 — без цены:**

```
გამარჯობა [სახელი]! ☕️ სანამ ფასს გეტყვით —
სახლისთვის გჭირდებათ თუ ბიზნესისთვის?
```

**Сообщение 2 — после ответа клиента:**

```
ამ მოდელის ფასდაკლებით [X] ლარია —
[1 ценность под клиента: ჩაშენებული საფქვავი / 8 სასმელი / ტრენინგი].
გსურთ [конкретный CTA]?
```

### Когда цену можно дать быстрее

- Клиент **уже** назвал модель, сегмент и бюджет в предыдущих сообщениях.
- Клиент **повторно** спрашивает цену после вашего вопроса — вы уже квалифицировали.
- Клиент прислал **фото товара с ценником** и спрашивает «актуально?» — подтвердите и добавьте CTA.

### Когда цену давать нельзя в первом ответе

- Первое сообщение в диалоге = только `ფასი?`
- Промо-рассылка без предварительного контакта
- Клиент спрашивает «сколько стоит кофе» без указания сорта/объёма

## 4. CTA — призыв к действию

### Теория

**CTA** — это не «напишите, если будут вопросы». Это **конкретное действие с параметрами**: время, место, канал, срок.

Слабый CTA перекладывает работу на клиента. Клиент устал решать — он ждёт, что **эксперт предложит следующий шаг**.

**Формула сильного CTA:**

```
[Глагол желания] + [что именно] + [когда/где] + [альтернатива A или B]?
```

Пример: `გსურთ ხვალ 15:00-ზე ვაკეში გაჩვენოთ, თუ ლინკი გამოგიგზავნოთ ონლაინ შესაძენად?`

### Слабые CTA — НИКОГДА не использовать

| Фраза | Почему убивает продажу | Чем заменить |
|-------|------------------------|--------------|
| `მოგვწერეთ თქვენთვის მისაღები ბიუჯეტი` | Клиент ждёт рекомендацию, не опрос | Предложите 2 модели в его диапазоне |
| `ნებისმიერ კითხვაზე მოგვმართეთ` | Нет времени, места, шага | `ხვალ 15:00-ზე ზარი` |
| `განიხილავთ ამ ვარიანტს?` | Да/нет без продолжения | `გსურთ დავაჯავშნოთ?` |
| `რას გულისხმობთ?` (на прямой запрос) | Клиент уже написал ясно | Дайте меню/каталог/ответ |
| `რამდენად დაინტერესებული ხართ?` | Пустой вопрос | `გსურთ დღეს დემო?` |

### Сильные CTA по ситуации

#### A. Клиент в Тбилиisi, домашняя покупка

```
გსურთ ხვალ 15:00-ზე ვაკეში, ზ. ფალიაშვილის 66-ზე გაჩვენოთ აპარატი?
წინასწარ მოგვწერეთ — Messenger-ის ფასდაკლებას გავააქტიურებთ.
```

#### B. Клиент в регионе / онлайн

```
გსურთ ლინკი გამოგიგზავნოთ ონლაინ შესაძენად?
მიწოდება 2-3 სამუშაო დღეში, მონტაჟი და ტრენინგი ჩართულია.
```

#### C. Клиент сомневается / сравнивает

```
გსურთ 2-3 ფოტო/ვიდეო გამოგიგზავნოთ და 5 წუთიანი ზარი,
სადაც ee.ge-ს შეთავაზებას შევადარებთ?
```

#### D. Клиент: «მოვიფიქრებ»

```
გასაგებია ❤️ რა გაჩერებთ — ფასი, ზომა თუ რძიანი სასმელების ხარისხი?
თუ გსურთ, დავაჯავშნოთ ფასდაკლება 48 საათით,
რომ ადგილი არ დაგიკარგოთ.
```

#### E. Клиент просит звонок

```
დიახ! 5 წუთში დაგირეკავთ [номер]-ზე.
თუ ახლა არудобно — მოგწერეთ სასურველი საათი.
```

#### F. Клиент готов купить завтра (горячий)

```
შესანიშნავია! დავაჯავშნოთ [მოდელი] თქვენს სახელზე?
ხვალ რომელ საათზე მოხვალთ — 12:00, 15:00 თუ 18:00?
მისამართი: ვაკე, ზ. ფალიაშვილის 66.
```

#### G. Кофе / расходники

```
რამდენი შეფუთვა გჭირდებათ და სად მოგიტანოთ?
თუ გსურთ, ახლავე გავაფორმებთ შეკვეთას — 2-3 დღეში მოგაწვდით.
```

#### H. После отказа банка в рассрочке

```
სამწუხაროა, რომ ბანკმა უარი თქვა 😔
მაგრამ გვაქვს სხვა ვარიანტები:
• გადახდა ერთიანად Messenger-ის ფასდაკლებით
• TBC-ის ცნობის განახლება ხვალ
• ვიზიტი შოურუმში — 10 წუთიანი დემო და ერთად ავარჩიოთ
რომელი ვარიანტი გირჩევნიათ?
```

### Правило «двух вариантов»

Хороший CTA даёт **выбор из двух конкретных действий**, не «да/нет»:

- `შოურუმი თუ ოнлайн ლინკი?`
- `დღეს ზარი თუ ხვალ 15:00-ზე ვიზიტი?`
- `ფოტო თუ ვიდეო?`

## 5. Ценности ДимКава — что и когда говорить

### Теория

Ценность — не абзац «доставка, монтаж, обучение, кофе, гарантия» в каждом сообщении. Это **1–2 аргумента под задачу клиента**.

| Ценность | Когда использовать | Фраза |
|----------|-------------------|-------|
| Обучение тренером | Дом / первый аппарат / кафе-новичок | `შეძენის შემდეგ ტრენერი დაგიყენებთ და ისწავლით` |
| Messenger-скидка | Любая онлайн-покупка | `Messenger-ით უფრო იაფია, ვიდრე მაღაზიაში walk-in` |
| Шоурум Ваке | Клиент в Тбилиisi | `ვაკე, ფალიაშვილის 66 — სცადეთ ყავა ადგილზე` |
| Официальная гарантия De'Longhi | Сомнения в качестве | `3 წლიანი ოфициальная გარანტია De'Longhi` |
| Доставка + монтаж | Регион / бизнес | `მიწოდება, მონტაჟი და ტრენინგი ჩართულია` |
| Кофе в подарок | После названия цены | `+ Blasercafe-ის ყავა საჩუქრად` |
| Референс кафе | B2B, высокая нагрузка | `მოგაწვდით კონტაქტს კაფეს, სადაც უკვე მუშაობს` |
| TBC рассрочка | Бюджет / «дорого» | `TBC-ის განვადებით ~80-100 ₾/თვე` |

**Не перегружайте:** если клиент спросил цену зерна — не перечисляйте про кофемашины и шоурум.

## 6. Возражения и «მოვიფიქრებ»

### Теория

«Подумать» почти никогда не значит «нет». Это значит: **есть страх или нехватка информации**.

Ваша задача — **назвать барьер** и **снять его одним шагом**.

### Алгоритм

1. Признать: `გასაგებია`
2. Спросить барьер: `რა გაჩერებთ — ფასი, ზომა თუ ...?`
3. Дать микро-аргумент (1 ценность)
4. CTA с низким порогом: фото, 5-мин звонок, бронь скидки

### «ძვირია» / бюджет 400–500 ₾

**Плохо:**

```
მოგვწერეთ ბიუჯეტი და გამოგიგზავნით ვარიანტებს
```

**Правильно:**

```
გასაგებია ☕️ 400-500 ლარის ბიუჯეტში გვაქვს მექანიკური მოდელი ~480 ₾-დან —
ესპრესო და ამერიკანო, რძე ხელით.
თუ ჩაშენებული საფქვავი გინდათ — ავტომატური 1299 ₾-დან, TBC განვადებით ~55 ₾/თვე.
გსურთ, ახლავე 2 ფოტო გამოგიგზავნოთ — 480-იანი და 1299-იანი?
```

### «Сравниваю с конкурентом»

```
გმადლობთ, რომ გვენდობით — სწორია, რომ შეადარებთ.
მითხარით, რომელი მოდელი/ბმული გაქვთ — ზუსტად იმავე ფუნქციებზე შევადარებთ.
გსურთ, 10 წუთიანი ზარი დღეს, თუ ხვალ შოურუმში გვერდიგვერდ გაჩვენოთ?
```

### «Нет рассрочки / банк отказал»

## 7. Закрытие сделки

### Теория

Закрытие — не «вы должны купить». Это **фиксация решения**, которое клиент уже почти принял.

**Сигналы готовности:**

- Назвал дату визита / «завтра приеду»
- Спросил реквизиты / оплату
- Спросил «есть в наличии?»
- Прислал адрес доставки
- Сказал «беру» / «გავაფორმოთ»

**В этот момент не** спрашивайте снова «дом или бизнес». **Действуйте:**

```
შესანიშნავია! დავიწყოთ შეკვეთა?
გთხოვთ, მომწeret: სახელი, ტელეფონი, მისამართი (ან სასურველი დრო визита).
```

### Мягкое закрытие (клиент ещё думает)

```
თუ გსურთ, დავაჯავშნოთ [მოდელი] ფასდაკლებით 48 საათით —
გადაწყვეტილების დრო გექნებათ, ფასი კი დაგიფიქსირდებათ.
```

## 8. Скорость ответа

### Теория

Скорость считается в **трёх блоках**:

| Блок | Когда | SLA | Цель |
|------|-------|-----|------|
| **Рабочее время** | пн–пт, 10:00–18:00 (Тbilisi) | ≤ **2 мин** (рабочие секунды) | Основной KPI оператора |
| **Вне смены** | вечер, выходные | ≤ **15 мин** (календарных) | Мягкий порог |
| **Общее** | календарное время | для сравнения | Не использовать как единственный KPI |

Рабочие секунды: если клиент написал в пятницу 17:55, а ответ в понедельник 10:05 — засчитывается ~10 мин рабочего времени, а не 63 часа календарных.

### Правила

1. **Рабочее время (10–18):** цель — ответ **≤ 2 мин**.
2. **Вне смены:** цель — **≤ 15 мин**; не оставлять клиента на сутки+.
3. **«დამირეკეთ» (позвоните):** звонок **в течение 15 мин**.
4. Проверка наличия: `5 წუთში გადაგიმოწმებთ მარაგს` — и вернуться через 5–10 мин.
5. Извинение за задержку — **в начале** ответа:
   ```
   ბოდიში შეყოვნებისთვის! ☕️ [основной ответ]
   ```

## 9. Приветствие, имя, тон

### Теория

Тон ДимKава: тёплый, экспертный, **грузинский**, с именем клиента.

| Элемент | Правило | Пример |
|---------|---------|--------|
| Приветствие | Всегда | `გამარჯობა [სახელი]!` |
| Имя | Из CRM, не выдумывать | `გამარჯობა ნინo!` |
| Эмодзи | 1–2 на сообщение | ☕️ ❤️ 😊 |
| Язык | Грузинский (клиент может на русском — ответ на грузинском OK) | Не англ. автоответ |
| Длина | Короткие абзацы, 1 вопрос | Не «простыня» на 10 строк |

**Критическая ошибка из CRM:** автоответ `Hi Sveta, thanks for following us...` на живой вопрос — **запрещено**.

## 11. Типичные ошибки — запретные фразы

Из анализа 42 + 24 диалогов — фразы, которые **часто повторяются** и **убивают конверсию**:

| # | Killer phrase | Почему | Замена |
|---|---------------|--------|--------|
| 1 | `ეს მოდელი ახლა აქციაშია — 1899₾` (первым) | Цена без контекста | Сначала вопрос |
| 2 | `მოგვწერეთ ბიუჯეტი` | Лень вместо экспертизы | 2 модели в диапазоне |
| 3 | `ნებისმიერ კითხვაზე მოგვმართეთ` | Пассивное закрытие | Время + место |
| 4 | `რას გულისხმობთ?` на ясный запрос | Раздражение | Конкретный ответ |
| 5 | Три цены в одном сообщении | «Price chaos» | Одна рекомендация |
| 6 | Дубль того же сообщения | Спам | Одно + follow-up через день |
| 7 | Противоречивые цены (1899 → 2859) | Потеря доверия | Одна модель = одна цена |
| 8 | Англ. автоответ | Клиент теряет интерес | Живой грузинский ответ |
| 9 | Отправка в сервис при запросе покупки | Потеря выручки | Проверка наличия + альтернатива |
| 10 | `რამდენად დაინტერესებული ხართ?` | Пустота | Демо / звонок / ссылка |

## 13. Чеклист перед отправкой

Перед каждым исходящим сообщением — 5 секунд:

- [ ] В **первом предложении** нет цены?
- [ ] Есть **имя** клиента?
- [ ] Задан **один** уточняющий вопрос (если ещё не квалифицировали)?
- [ ] Цена (если есть) — **в контексте** задачи клиента?
- [ ] В конце — **конкретный CTA** (время / место / звонок / ссылка)?
- [ ] В сообщении **одна** основная цена, не три?
- [ ] Язык — **грузинский**, не автоответ?
- [ ] Ответ отправлю **≤ 2 мин** в рабочее время (10–18)?
