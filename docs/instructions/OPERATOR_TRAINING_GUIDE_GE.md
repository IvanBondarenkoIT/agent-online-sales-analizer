## 1. მთავარი წესი: 4 ნაბიჯი

1. გამარჯობა + სახელი  
2. **ერთი** დამაზუსტებელი კითხვა  
3. ფასი **კონტექსტში**  
4. **კონკრეტული** CTA (დრო / ზარი / ლინკი / დაჯავშნა)

პირველ წინადადებაში ფასი არა. `მოგვწერეთ ბიუჯეტი` — აკრძალულია.

---

## 2. საჭიროების გამოვლენა

იკითხე რაც მოდელს ცვლის: სახლი/ბიზნესი, ჭიქები, რძიანი, ვადა.

| მაგალითი |
|----------|
| `სახლისთვის თუ ბიზნესისთვის?` |
| `დღეში რამდენ ფინჯანს/ჭიქას?` |
| `რძიანი კაპუჩინო გინდათ ერთი ღილაკით?` |

არა 5 კითხვის დაკითხვა ზედიზედ.

---

## 3. პასუხი «ფასი?» / «რა ღირს?»

**ცუდი:** `ეს მოდელი ახლა აქციაშია — 1899₾`  
**კარგი:**

```
გამარჯობა [სახელი]! ☕️ სანამ ფასს გეტყვით —
სახლისთვის გჭირდებათ თუ ბიზნესისთვის?
```

პასუხის შემდეგ: ერთი ფასი + 1 სარგებელი + CTA.

---

## 4. CTA

| სუსტი | ძლიერი |
|-------|--------|
| `მოგვწერეთ ბიუჯეტი` | `ხვალ 15:00 ვაკე, ფალიაშვილის 66` |
| `ნებისმიერ კითხვაზე...` | `ლინკი ონლაინ` / `5 წუთიანი ზარი` |
| `განიხილავთ?` | `დავაჯავშნოთ ფასდაკლება 48 საათით?` |

`მოვიფიქრებ`-ზე: რა გაჩერებთ + დაჯავშნა / ფოტო / ზარი.

---

## 5. დიმკავას ღირებულებები

ტრენერი, გარანტია, მიწოდება/მონტაჟი, შოურუმი — **საჭიროების შემდეგ**, არა კითხვის ნაცვლად.

---

## 6. წინააღმდეგობები

- «ძვირია / უფრო იაფი?» → არა კედელი «სხვები 3500-დან». განვადება, დემო, ბიუჯეტის მოდელი.  
- «მოვიფიქრებ» → ბლოკერი + კონკრეტული ნაბიჯი.  
- ბანკი გაიჭედა → გადახდის ალტერნატივა + აპარატის დაჯავშნა, არა «მხოლოდ ბანკია».

---

## 7. დახურვა

დააფიქსირე: ვიზიტის დღე/საათი, ზარი, ლინკი, დაჯავშნა. `next_step_fixed` ახლა ძალიან დაბალია — ეს მთავარი ჩავარდნაა.

## 10. სცენარები

### 10.1 ფასი კონტექსტის გარეშე
→ §3.

### 10.2 B2B / კაფე
ჭიქები → მოდელი → დემო → ვიზიტის დრო.

### 10.3 სათადარიგო / სერვისი
შეძენა დიმკავაში ≠ «თვითონ დარეკეთ სერვისში». ჯერ ჩვენი მარაგი; თუ სერვისი — ტელეფონი **და** თანხლება.

### 10.4 დაბრუნებული ლიდი
CRM ისტორია: `მაისში [მოდელი] გირჩიეთ — კვლავ აქტუალურია?`

### 10.5 მარაგში არაა
ორი ალტერნატივა + შეტყობინება/შეკვეთა/ვიზიტი.

### 10.6 საჩივარი შესყიდვის შემდეგ
ემპათია → დაპირების შემოწმება → ტრენერის სლოტი. არა `სად შეიძინეთ?`.

### 10.7 «უფრო იაფი გაქვთ?»
ერთი მოდელი ბიუჯეტში + განვადება + დემო.

## 12. CRM განხილვები (იყო → უნდაიხდა) — 21–27.07

### 12.0 შეჯამება

| კლიენტი | თარიღი | გაკვეთილი |
|---------|--------|-----------|
| Lali Gvedashvili | 23.07 | CRM ისტორია |
| Mariana Kapanadze | 22.07 | მარაგი → 2 ვარიანტი |

| Bacho Iluridze | 24.07 | დაპირება = შოურუმი |
| Anamaria Noniashvili | 27.07 | «უფრო იაფი?» + B2B |
| Madonna / გოგა | 27.07 | ერთი მოდელი = ერთი ფასი |
| Khatia Kalandaze | 22.07 | განვადება ბანკის გარეშე დახმარებით |

### 12.1 Lali — დაბრუნებული ლიდი
**იყო:** ისევ 1899 + «სახლისთვის?»  
**გაიხდა:** `გამარჯობა! მაისში [მოდელი] 1200₾ გირჩიეთ — კვლავ აქტუალურია? ხვალ 15:00 ვაკეში გაჩვენოთ?`

### 12.2 Mariana — მარაგში არაა
**იყო:** მხოლოდ «ტაბლეტები აღარ გვაქვს».  
**გაიხდა:** ნაკრები / ანალოგი / «შეგატყობინებთ მარაგზე» + ვიზიტი ან შეკვეთა.

### 12.3 Marita — ფასდაკლების ქაოსი
**იყო:** −15% → «არ შეიძლება» → არეულობა.  
**გაიხდა:** ერთი წერილობითი საბოლოო ფასი გადახდამდე.

### 12.4 Bacho — შოურუმი ≠ ჩატი
**იყო:** დაპირებული საჩუქარი/სწავლება; მაღაზიაში უარი + `სად შეიძინეთ?`.  
**გაიხდა:** შემოწმება ვიზიტამდე; საჩივარზე — ბოდიში + ტრენერის სლოტი დღეს.

### 12.5 Anamaria — «უფრო იაფი?»
**იყო:** ფასი პირველი; drive-through-ზე «სახლისთვის?»; «უფრო იაფი» → არა, სხვები 3500-დან; «მოვიფიქრებ» CTA-ს გარეშე.  
**გაიხდა:** B2B კონტექსტი → ერთი მოდელი → განვადება/დემო → დაჯავშნა 48სთ.

### 12.6 Madonna / გოგა — ფასების flip
**იყო:** 2859 ↔ 1899; თვეები ერთი ცხრილის გარეშე.  
**გაიხდა:** მოდელი — ფასი (ერთი სტრიქონი) + ვიზიტის თარიღი.

### 12.7 Khatia — ბანკი
**იყო:** `ვერ დაგეხმარებით… საბანკო პროცესია`.  
**გაიხდა:** გადახდის ალტერნატივა + აპარატის დაჯავშნა + ზარი.
