# Как отвечать на «ფასი?» / «რა ღირს»

## Плохо (паттерн Цена-Молчание)

```

გამარჯობა, ფასდაკლებით 1899 ლარია... სახლისთვის ეძებთ?

```

Цена в первом предложении — клиент получает цифру и уходит думать.

## Хорошо

```

გამარჯობა! სანამ ფასს გეტყვით — სახლისთვის გჭირდებათ თუ ბიზნესისთვის? რომელი სასმელს მიირთმევთ ყველაზე ხშირად? ☕️

```

После ответа клиента:

```

ამ მოდელის ფასდაკლებით 1899 ლარია — ჩაშენებული საფქვავით და 8 სასმელით. გსურთ ხვალ 15:00-ზე ვაკეში გაჩვენოთ, თუ ლინკი გამოგიგზავნოთ ონლაინ შესაძენად?

```
